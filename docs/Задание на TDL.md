#   задание для ии по отслеживанию и планированию задач агентом. Ревит проекты 
нужно создать задание для ии по отслеживанию и планированию задач агентом. 
Цель - мощный план по которому агент не сможет соврать и не выполнить задачу.
за основу берем правила:
1. Используем структуру (поля модели)
   1. СДР (структурная декомпозиция работ)
   2. Проект
   3. Модуль
   4. Класс
   5. слой (ядро, UI,инфраструктура, фичи,тесты) по чистой архитектуре (упрощенно)
   6. статус -открыто/выполнено
   7. задание(запрос, выполненение) с гиперссылками
   8. Отчетный документ по этапу для пользователя (аналитическая записка, dwf чертеж, Thre js) что бы пользователь мог оценить результат.
   9. цель (для теста например входные данные, что проверяем)
   10. Не используем суммарную задачу для планирования (суммарная задача есть в UI но используем ее как extender,смотри пример ui)
   11. Структуру осуществляем через поле СДР (до 3-4) уровня вложенности.
  пример(нужно сделать его по струтуре выше+дополнительные поля)
    СДР|Наименование|Описание|Слой|Статус|начало|завершение|
  Этап1| сделать снимок модели ревит|получаем видовые экраны для тестов

  1.1 получить количество видовых экранов
  1.1. моудль....
  1.1.1. класс...
  1.1.1.1. тест
в результате мы должны иметь таблицу TDL с фильтрацией которую заполняет агент. Предусмотреть гиперссыкли на документы. Карточку задачи
