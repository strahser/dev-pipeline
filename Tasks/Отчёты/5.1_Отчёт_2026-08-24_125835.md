# ОТЧЁТ: 5.1 — Агрегат /api/activity по этапам + строка в карточке проекта

Дата: 2026-08-24 12:58 (постановка 12:58:35)
Статус: done

## Что было не так

- `/api/activity` отдавал только плоский список коммитов с распознанным `card`
  (activity.py:30–49), группировки по этапам не было.
- Карточка проекта в панели (`renderProjectCard`) показывала только прогресс
  этапов из статусов плана (plan_api.py:652–670); блок «Активность» (`actList`)
  был достижим только внутри вкладки плана, а не на карточке пульса.
- Не было способа из карточки проекта увидеть «что сделано за неделю» по этапам.

## Что сделано

1. **pipeline/activity.py** — добавлены функции:
   - `stage_of(card)` — этап = префикс id до последней точки (как `_stage_id`
     в plan_runner.py:323–325); без card/без точки → `'—'`.
   - `group_stages(commits)` — группировка коммитов по этапу, возвращает
     `[{stage, commits, last_subject, last_date, feat_n, fix_n}]`,
     отсортировано по последней дате (свежие сверху); `feat_n`/`fix_n` считаются
     по префиксу (`feat`/`fix`).

2. **server/app.py** — `/api/activity` принимает параметр `group=stages`:
   возвращает `{project, group:'stages', stages:[...]}` через `group_stages`.
   Без `group` — прежний плоский список (обратная совместимость).

3. **server/plan_api.py** — в `api_pulse_all` для каждой карточки проекта добавлены
   `stage_activity` (агрегат по этапам за 7 дней) и `activity_total` (число коммитов),
   чтобы карточка пульса могла показать строку активности.

4. **server/static/dashboard.html**:
   - `renderProjectCard` — под прогресс-барами добавлена строка
     «💾 коммиты за 7 дней: N · <этап>: M (+Ffeat · Gfix) …», клик по этапу
     открывает ленту активности этапа.
   - Новый модал `stageFeedOverlay` + функции `openStageFeed`/`loadStageFeed`/
     `closeStageFeed` — лента коммитов выбранного этапа (30 дней) через
     `/api/activity?days=30`.

5. **tests/test_activity.py** — добавлены тесты:
   - `GroupStagesTest.test_group_stages` — агрегат на фикстуре с коммитами
     `plan/A-1.1`, `plan/A-1.2`, `fix`, без префикса;
   - `GroupStagesTest.test_api_group_stages_endpoint` — временный git-репозиторий
     и запрос `/api/activity?group=stages`.

  `/api/activity?days=30`. Достаточно для «ленты активности этапа» по критерию 2.

   прогресс-барами этапов строка «💾 коммиты за 7 дней: …»; клик по этапу
   открывает ленту коммитов этапа.
