# ОТЧЁТ: 3.1 — Точки входа UI: План / Чат / Входящие; чистка мёртвого кода

Дата: 2026-08-24
Статус: done
Исполнитель: subagent (карточка 3.1 плана)

## Что было не так (факты по коду)
- `boot()` вызывал только `buildShellLite()` — главный экран «Обзор проектов» без точек
  входа в полный план, чат и входящие. `buildShell` (полный план с фильтрами + «Активность»),
  `openChat`, `openRequests` никем не вызывались (мёртвые функции/экраны).
- Дубль `refreshData` (две одинаковые функции подряд — вторая побеждала молча).
- `setProject` обращался к несуществующему `#projectSelect` (в lite-режиме селектора в шапке
  не было вовсе).
- `setInterval(refreshActivity, 60000)` крутился впустую: в lite-режиме элемента `#actList`
  нет — тик каждые 60 с завершался ранним `return`.

## Что сделано (файлы)
Файл: `server/static/dashboard.html`

1. **Шапка (header)**: добавлены `#projectSelect` (селектор активного проекта, ★ = есть план),
   кнопки «🏠 Обзор» (`goHome`), «📋 План» (`openPlan`), «💬 Чат» (`openChat`), «📥 Входящие»
   (`openRequests`) + существующие («🗂 Сессии», «🛡 Менеджер», «❓ Вопросы · ⏸ Чекпоинты»).
2. **Режимы просмотра**: добавлена переменная `viewMode` ('home' | 'plan') и функции
   `goHome()` (обзор всех проектов, lite-каркас) и `openPlan()` (полный план: `buildShell` +
   фильтры + таблица + «Активность»).
3. **`setProject`** привязан к реальному `#projectSelect`; при выборе проекта с «Обзора»
   сразу строит каркас плана.
4. **Дубль `refreshData` удалён** — осталась одна функция (SPA-обновление без «дёргания»).
5. **Интервал `refreshActivity`** больше не крутится впустую: добавлен `startActivityTimer()`,
   который запускает `setInterval` только когда `#actList` существует (после `buildShell`);
   на «Обзоре» интервала нет. Сама `refreshActivity` по-прежнему делает ранний `return`,
   если `#actList` отсутствует.
6. **«Активность» достижима** — блок `📜 Активность (git, 7 дней)` рендерится в живом UI
   внутри `buildShell` (экран «План»), куда теперь есть кнопка из шапки.
7. **`boot()`** теперь заполняет селектор проектов через новую `loadProjects()` (из
   `/api/projects`).

## Доказательства (проверки по критериям приёмки)
- Критерий 1 (кнопки в шапке, каждая открывает свой экран): в шапке есть
  `onclick="goHome()"`, `onclick="openPlan()"`, `onclick="openChat()"`, `onclick="openRequests()"`;
  `openPlan()` → `buildShell()` (рендерит `#actList`), `openChat()` → `openChat()` открывает
  `#chatPanel`, `openRequests()` → `openRequests()` открывает `#requestsOverlay`.
  «Активность» рендерится в `buildShell` (`#actList`) и в `loadPulse` (лента/коммиты).
- Критерий 2 (дубль refreshData устранён; setProject привязан к реальному элементу):
  findstr показал единственную `async function refreshData(` (строка 1371);
  `setProject` пишет в существующий `#projectSelect` (строка 226 в HTML).
- Критерий 3 (setInterval(refreshActivity) только при существующем контейнере):
  `startActivityTimer()` проверяет `if (!$('actList')) return;` перед `setInterval`
  (строки 488–491); вызывается только из `buildShell` (строка 1506).
- Критерий 5 (регресс серверных эндпоинтов): `python -X utf8 tests/run_all.py` → **Ran 215
  tests, OK (0 падений)**.
- Критерий 4 (ручная проверка на живом сервере) — требует живого сервера, выполняется
  владельцем; изменён только статический dashboard.html, серверные эндпоинты не трогала.

## Как проверить
1. Поднять сервер: `start-server.bat` (или `python -X utf8 -m server --port 8787`).
2. Открыть http://127.0.0.1:8787/ — в шапке селектор проекта и кнопки
   «🏠 Обзор / 📋 План / 💬 Чат / 📥 Входящие».
3. Выбрать проект ★ → «📋 План» — полная таблица с фильтрами + «Активность (git, 7 дней)».
4. «💬 Чат» — панель чата; «📥 Входящие» — список заданий; «🏠 Обзор» — карточки всех проектов.
5. Регресс: `python -X utf8 tests/run_all.py` → 0 падений.
