# ОТЧЁТ: 4.1 — Роль manager: opencode-сессия с приёмкой этапов

Дата: 2026-08-24
Статус: done

## Что было не так
Менеджер был «пустой» страховкой: `project_manager.py:178–181` — `while True sleep(30)`:
не читал GOAL.md, не понимал указания, этапы принимать не мог. Роли manager не было
ни в стартовых промптах ролей (`ROLE_STARTERS`, `tui_cycle.py`), ни как навыка;
кнопка «🛡 Менеджер» запускала python-цикл `project_manager.py`, а не видимую
opencode-сессию.

## Что сделано
### dev-pipeline (репозиторий конвейера)
1. `agents/tui_cycle.py`:
   - добавлена роль `ROLE_STARTERS["manager"]` — «ОБЩИЙ МЕНЕДЖЕР конвейера (НА ВСЕ
     проекты)»: следит за проектами (/api/pulse_all, /api/checkpoints, /api/sessions),
     принимает этапы (pending → прочитай GOAL.md + вердикты + diff/log → пишет
     `Tasks\Конвейер\checkpoints\<CARD>.decision.json` `{decision: approve|retry,
     comment, actor: manager}`), спорное — вопрос владельцу через `Tasks\Вопросы`,
     границы «код НЕ правишь».
   - `auto_task_manager()` — автозадание для общего менеджера: сводка по ВСЕМ
     проектам из `/api/pulse_all` (прогресс, чекпоинты к приёмке, открытые вопросы,
     зависшие).
   - `build_base_prompt` — для роли `manager` вместо `auto_task(cfg)` (одного проекта)
     подставляет `auto_task_manager()`.
   - `--project` стал необязательным; `--headless` — флаг для роли manager
     (запускает страховочный python-цикл `project_manager`); роль manager без
     проекта берёт первый проект как рабочий (для handoff/прав/папки конвейера),
     а промпт — сводка по всем проектам.
2. `server/app.py` — `POST /api/chat/agents/terminal` для `role=manager` теперь
   запускает ВИДИМУЮ opencode-сессию `agents/tui_cycle.py --role manager`
   (вместо `project_manager.py`); страховочный цикл доступен флагом `--headless`.
3. `server/static/dashboard.html` — кнопка «🛡 Менеджер» (строка 246) уже вызывала
   `openTerminal('', 'manager')` → теперь через endpoint поднимает tui_cycle manager.
4. `tests/test_manager.py` (НОВЫЙ) — тест manager-заглушки: роль в ROLE_STARTERS +
   фейковый клиент/часы + pending-чекпоинт → пишет валидный `<CARD>.decision.json`
   (actor: manager) → `wait_decision` разбирает как approve/retry; автозадание
   менеджера не падает без сервера.
5. `tests/test_server.py` — `test_manager_global_without_project` обновлён под новое
   поведение (менеджер → `tui_cycle.py --role manager`, project не нужен).
6. `tests/run_all.py` — зарегистрирован `test_manager`.
7. `examples/devpipeline/pipeline.yaml` — baseline тестов обновлён 121 → 228 (после
   добавления нового теста).
8. `docs/runbook.md` — новый раздел «4.3. Общий менеджер (кнопка «🛡 Менеджер»)»:
   opencode-сессия, приёмка чекпоинта, границы («код НЕ правит»), страховочный
   `--headless`, handoff-цикл, автозадание из /api/pulse_all.

### revit-skills (навык)
