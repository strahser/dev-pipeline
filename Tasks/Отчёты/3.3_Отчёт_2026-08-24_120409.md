## Что было не так (факт по коду)

- Модалка «🗂 Сессии» (`server/static/dashboard.html`) не имела фильтра по статусу:
  бэкенд `GET /api/sessions?status=` уже фильтрует (`app.py:1470-1472`), UI звал его без `status`.
- Массовых операций не было: `POST /api/sessions/cleanup` (`app.py:1576-1601`) вообще не вызывался
  из панели (инцидент 2026-08-23: 59 мёртвых сессий чистились вручную SQL-ом); массового
  kill stalled тоже не было.
- Заметка сессии обрезалась до 60 символов без опознавания префикса `handoff:`
  (кандидаты рестарта, механика 8.4/6.2), бейджа и сортировки вверх не было.
- Форма «➕ Новый агент» была жёстко спрятана `display:none` (`.agent-create`),
  кнопки для её вызова не существовало.

## Что сделано (пути файлов)

Реализация выполнена в `server/static/dashboard.html` (коммит `bccf686`,
`plan/3.3: сессии: фильтр статуса, cleanup с keep_handoff, kill stalled, бейдж handoff, кнопка ➕`):

1. **Фильтр статуса**: `<select id="sessionsFilter">` (все/stalled/failed/killed/done) над
   таблицей субагентов; `onchange` → `loadSessions()`, значение подставляется в
   `GET /api/sessions?project=…&status=…` (dashboard.html:331, :2097-2105).
2. **«🧹 Очистить завершённые»** (`sessionsCleanup`, dashboard.html:2025-2035): чекбокс
   `#cleanupKeepHandoff` («сохранить handoff», checked по умолчанию) →
   `POST /api/sessions/cleanup?project=…&keep_handoff=1|0`; `confirm()`; результат
   (deleted/kept) — в тосте «Удалено: N, handoff сохранено: M».
3. **«⛔ Kill stalled»** (`killAllStalled`, dashboard.html:2037-2053): `confirm()` → выборка
   `GET /api/sessions?status=stalled` текущего проекта → последовательный
   `POST /api/sessions/{sid}/kill` (for…await); тост «Stalled убито: N, ошибок: M».
4. **Бейдж handoff**: в `renderSessionTable` заметки с префиксом `handoff:` получают бейдж
   «🤝» перед текстом и сортируются наверх (`.sort` по `startsWith('handoff:')`,
   dashboard.html:2063-2081).
5. **«➕ Новый агент»**: кнопка в шапке модалки (`toggleAgentCreate`) показывает/скрывает
   `.agent-create` (dashboard.html:2019-2023); форма горизонтально разложена.
