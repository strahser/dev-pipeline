# КАРТОЧКА 1.1 — Честный финал сессии: успех без отчёта = done

## Цель
ролевые сессии (executor/controller/creator… из POST /api/agents), отработавшие успешно, получают статус done, а не failed — исчезает источник ложных рестартов (инцидент 2026-08-23: failed с rc=0 → вечный перезапуск супервизором).

## Описание (факт по коду)
session_worker.run_session ставит done только при
  `rc == 0 AND report AND Path(report).exists()` (:258). Инструкция ролей из agent_create
  не содержит `report`, поэтому любой успешный прогон маркируется failed.

## Входные данные
agents\session_worker.py (run_session); server\app.py (agent_create);
  tests\test_server.py (AgentSpawnTest), tests для worker-заглушки.

## Задание

1. Тест: инструкция БЕЗ `report`, rc=0 → статус `done`, заметка «отчёт не требуется».
2. Тест: инструкция С `report`, файл не создан → прежнее поведение: `failed`
